# 展示介面規範

使用 **Streamlit** 或 **Gradio**。

## 必備區塊一：使用者對話／指令區

- 輸入欄
- AI 回應

## 必備區塊二：後台工程驗收區

每則 AI 回應下方需有以下展開欄（Streamlit：`st.expander`；Gradio：`gr.Accordion`），內容取自 `/chat` 回傳的對應欄位：

| 展開欄 | 顯示內容 | 來源欄位 |
| --- | --- | --- |
| Sources | 引用段落的 id 與原文 | `sources` |
| 護欄判定 | 是否觸發、類別、動作 | `guardrail` |
| Agent 思考步驟 | 依序列出各步驟 | `trace` |
| 路由 | 地端或雲端 | `route` |

各角色另需顯示：

| 角色 | 顯示內容 |
| --- | --- |
| 教師 AI 助教 | 每題的 `source_ids` 與 `critic` 查核結果 |
| 家長 AI 幫手 | 攔截紀錄列表 |
| 校長 AI 決策助手 | 每項建議的 `evidence`（查詢與結果） |

`ui/app.py` 已包含共通展開欄，以及 `questions`、`recommendations` 的顯示；家長組的攔截紀錄需自行加入。
