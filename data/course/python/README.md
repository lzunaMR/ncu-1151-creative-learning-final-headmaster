# Python 程式設計課程：彙總資料集

一門大學 Python 程式設計課程（48 位修課學生）在課程平台上的**練習題與成績彙總**。由平台管理者授權，從平台資料庫備份以 `scripts/build_course_dataset.py` 產生。

**本資料集不含任何個人層級的資料**，每一列都是一道題或一個成績項目的彙總。

> 這不是助教提供的資料，系統**預設不使用**；以 `ENABLE_COURSE=1`（或 `demo.ps1 -Course`）開啟。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `problems.md` | 43 道練習題的題目說明（題目、輸入、輸出、提示），每題以 `### 題號 標題` 開頭，可直接拿來做 RAG |
| `problem_stats.csv` | 每題的作答人數、通過人數、通過率、提交次數與錯誤類型比例 |
| `grade_item_stats.csv` | 12 個成績項目的人數、平均、中位數、四分位數、標準差、分數區間人數 |

題號沿用平台的題目代號：`PY-C3-A2` 代表第 3 單元（C3）的 A2 題。單元內的 A／E／P 是平台原本的題目分組。

## `problem_stats.csv` 欄位

| 欄位 | 說明 |
| --- | --- |
| `problem_id`、`title` | 題號、題目名稱 |
| `students_attempted` | 至少提交過一次的學生數（四捨五入到 5 的倍數） |
| `students_passed` | 至少有一次 Accepted 的學生數（四捨五入到 5 的倍數） |
| `pass_rate` | 通過人數／作答人數（小數第 2 位） |
| `accepted_share` | 所有提交中 Accepted 的比例（**以提交次數計**，不是人數） |
| `submissions` | 提交總次數 |
| `median_submissions_per_student` | 每位作答學生提交次數的中位數 |
| `wrong_answer_share`、`runtime_error_share`、`time_limit_share` | 所有提交中 Wrong Answer、Runtime Error、Time Limit Exceeded 的比例 |

## `grade_item_stats.csv` 欄位

| 欄位 | 說明 |
| --- | --- |
| `item` | 成績項目：每週的 Intention、CodingHelp（平台自動計分，多為 0 或 100）與 C1～C4 隨堂考 |
| `max_score` | 滿分 |
| `students` | 有成績的學生數（四捨五入到 5 的倍數） |
| `mean`、`std` | 平均、標準差（取整數） |
| `median`、`p25`、`p75` | 中位數、第 25 與第 75 百分位數 |
| `n_0-59` … `n_90-100` | 各分數區間的人數（四捨五入到 5 的倍數，加總不一定等於 `students`） |

## 去識別化做法

1. **只計入該課程的修課學生**：排除教師帳號，以及在平台上作答、但不是這門課成員的帳號。
2. **不輸出任何個人資料**：姓名、學號、email、密碼、登入紀錄、提交時間、程式碼內容、與聊天機器人的對話都不輸出。
3. **不輸出考試內容**：排除考試題（`exam_mode` 或 `is_hidden`）、期末考題（FIN／FINAL 開頭）、修課學生都沒有作答的題目，也不輸出任何題目的參考解答、測試資料與範例輸入輸出。
4. **小樣本抑制**：作答或有成績的人數少於 5 時，該列的統計全部留空。通過人數只有在「通過」與「未通過」都是 0 或至少 5 人時才輸出；分數區間只有在每個非零區間都至少 5 人時才輸出，否則平均、標準差與區間全部留空。
5. **防止用加減反推**：人數一律四捨五入到 5 的倍數；平均與標準差取整數、通過率取到小數第 2 位。例如「48 位修課、44 人作答」會讓人推出「4 人沒作答」，四捨五入後就看不出來；0／100 計分的項目，精確的平均也會直接透露確切人數。
6. 產生後逐行人工檢查三個檔案，確認沒有殘留的姓名、學號、email、網址或 HTML。題目中的人名（王小明、小明、小美、小華）是題目情境裡虛構的角色。

## 限制

- 人數經過四捨五入，**不適合拿來做精確的人數計算**，只適合看相對高低（例如哪一題的錯誤比例最高）。
- C6 之後的作答人數明顯變少，C7、C8 每題不到 5 人作答，因此統計留空。
- 「Intention」「CodingHelp」由平台自動計分，多為 0 或 100，平均分數比較接近「完成率」。
- 原始資料庫備份含個人資料，**絕對不可放進 repo**（`.gitignore` 已排除 `*.sql`、`*.sql.gz`）。需要重新產生時，由管理者在本機執行：

```bash
python scripts/build_course_dataset.py <資料庫備份.sql>
```
