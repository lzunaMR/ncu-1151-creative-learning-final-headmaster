### PY-C3-A2 Reversed Words

reverse()
範例：
myList = [ 'apple', 'banana', 'grape' ]
myList.reverse()
print(myList)
結果為 ['grape', 'banana', 'apple']
【把字串List裡的字串連接】
"分隔符號".join(myList)
範例：
myList = [ 'apple', 'banana', 'grape' ]
new_string = "~".join(myList)
print(new_string)
結果為apple~banana~grape

輸入：一行

輸出：一行
句子以單字為單位反轉，單字之間以一個空格間隔

### PY-C6-A2 The 3n + 1 problem

題目：給定一個整數 n，依照以下規則產生數列：
1. 輸出 n
2. 如果 n = 1，停止
3. 如果 n 是奇數，n = 3*n + 1
4. 如果 n 是偶數，n = n / 2
5. 重複以上步驟
例如：
輸入 22
數列為：
22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
這個數列的長度（包含 1）稱為 cycle length，此整數 n 的 cycle length 為 16。
現在給你兩個正整數 i 和 j，
請找出從 i 到 j（包含 i 和 j）之間，
所有數字的 cycle length，並輸出其中的最大值。
據推測此演算法對任何整數而言會終止 (當列印出 1 的時候)。雖然此演算法很簡單，但以上的推測是否真實卻無法知道。然而對所有的n ( 0 < n < 1,000,000 )來說，以上的推測已經被驗證是正確的。

輸入：兩行
分別為 i 和 j (0< i，j < 1,000,000 且 i < j)

輸出：一行
一個整數，輸出 i, j 和介於 i, j 之間的數所產生的數列中最大的 cycle length

1 ≤ n ≤ 100

輸出：依序輸出從 n 到 1 的整數。
倒數結束後，輸出 GO。
每個輸出內容都要放在不同的一行。

提示：先將 number 設定為 n。
只要 number 大於或等於 1，就輸出 number，並將 number 減少 1。
離開 while 迴圈後，再輸出 GO。

### PY-C7-E1 字串計數器

輸入：一個字串

### PY-C7-P1 每日餐費統計

題目：小明想要統計一天的餐費。請撰寫一個程式，讓使用者輸入三筆餐點資料，每筆資料包含「餐點名稱」與「金額」存入字典中，並算出總花費。

輸入：輸入共有三行，每行包含一個字串（名稱）與一個整數（金額），中間以空格分隔：
早餐名稱 早餐金額
午餐名稱 午餐金額
晚餐名稱 晚餐金額

輸出：輸出總花費

### PY-C8-A1 數值比大小

題目：請寫一個函式max_min(number)，傳入兩個整數number1與number2，若number1<=number2回傳Yes，否則回傳No。
function名稱要一模一樣，括號裡的參數名稱可以不一樣，但參數個數一定要一致

### PY-C8-P1 預算管控

題目：請寫一個函式名為budget_control(budget, spending)，接收兩個整數作為參數(預算(budget)、花費(spending))。
回傳規則：
若 花費大於預算，請回傳字串 'Over budget'
否則（花費小於或等於預算），請回傳字串 'Under budget'
注意：function名稱要一模一樣，括號裡的參數名稱可以不一樣，但參數個數一定要一致

輸入：無須輸入
系統會自動代入兩個對應的參數

輸出：回傳'Under budget'或'Over budget'
只需return，不需要print
