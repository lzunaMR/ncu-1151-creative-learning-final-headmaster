# 第一章 一元一次方程式

> 本講義由課程助教自編，僅供 1151 創意學習期末專題使用。
> 每個 `###` 標題前的編號是段落 id（例如 `1-3-3`）。切塊方式自行決定，但回傳 `sources` 時要用這些段落 id 標示來源。

## 1-1 代數式與方程式

### 1-1-1 用文字符號代表數

當一個數還不知道是多少時，可以先用英文字母（例如 x、y）代表它。例如「某數的 3 倍再加 5」可以寫成 3x + 5。像 3x + 5 這樣由數字、文字符號和運算符號組成的式子，稱為代數式。

在代數式中，數字與文字相乘時，乘號可以省略，並把數字寫在前面，例如 3 × x 寫成 3x；1 × x 寫成 x。

### 1-1-2 方程式的意義

用等號「=」連接兩個式子，並且含有未知數的等式，稱為方程式。例如 3x + 5 = 20 是一個方程式，其中 x 是未知數。等號左邊稱為左式，等號右邊稱為右式。

5 + 3 = 8 雖然是等式，但沒有未知數，所以不是方程式。

### 1-1-3 一元一次方程式

一個方程式如果只含有一個未知數（一元），而且未知數的次數是 1（一次），就稱為一元一次方程式。

例如：
- 2x − 7 = 3 是一元一次方程式。
- x + y = 10 有兩個未知數，不是一元一次方程式。
- x² + 1 = 5 中 x 的次數是 2，不是一元一次方程式。

### 1-1-4 方程式的解

能使方程式左右兩邊相等的未知數的值，稱為這個方程式的解。

例如：把 x = 5 代入 3x + 5 = 20，左式 = 3 × 5 + 5 = 20 = 右式，所以 x = 5 是 3x + 5 = 20 的解。把 x = 4 代入，左式 = 17 ≠ 20，所以 x = 4 不是它的解。

求出方程式的解的過程，稱為解方程式。

## 1-2 等量公理

### 1-2-1 等量加減公理

如果 a = b，則：
- 等量加法公理：a + c = b + c
- 等量減法公理：a − c = b − c

也就是說，等號兩邊同時加上（或減去）同一個數，等式仍然成立。可以想像成一個平衡的天平，兩邊同時放上或拿走一樣重的東西，天平仍然平衡。

### 1-2-2 等量乘除公理

如果 a = b，則：
- 等量乘法公理：a × c = b × c
- 等量除法公理：a ÷ c = b ÷ c（c 不可以是 0）

也就是說，等號兩邊同時乘以（或除以）同一個數，等式仍然成立。要特別注意，不能同時除以 0。

### 1-2-3 例題：用等量公理解方程式

例題 1：解 x + 7 = 12。
兩邊同時減 7：x + 7 − 7 = 12 − 7，得 x = 5。

例題 2：解 3x = 18。
兩邊同時除以 3：3x ÷ 3 = 18 ÷ 3，得 x = 6。

例題 3：解 x ÷ 4 = 2。
兩邊同時乘以 4：x ÷ 4 × 4 = 2 × 4，得 x = 8。

## 1-3 移項法則

### 1-3-1 移項：加減互換

把方程式中的某一項，改變符號後從等號的一邊移到另一邊，稱為移項。移項其實是等量加減公理的簡便寫法：
- 原本是「加」的項，移到另一邊變成「減」。
- 原本是「減」的項，移到另一邊變成「加」。

例如 x + 7 = 12，把 +7 移到右邊變成 −7：x = 12 − 7 = 5。

### 1-3-2 移項：乘除互換

由等量乘除公理可以得到：
- 未知數的係數是「乘」的，移到另一邊變成「除」。
- 未知數是「被除」的，移到另一邊變成「乘」。

例如 3x = 18，可以寫成 x = 18 ÷ 3 = 6；x ÷ 4 = 2，可以寫成 x = 2 × 4 = 8。

### 1-3-3 例題：解 3x + 5 = 20

步驟一：把常數項 +5 移到右邊，變成 −5：3x = 20 − 5，得 3x = 15。
步驟二：把係數 3 移到右邊，變成除以 3：x = 15 ÷ 3，得 x = 5。

解題時的原則是：先處理加減，把含未知數的項留在一邊、常數留在另一邊；再處理乘除，求出未知數。

### 1-3-4 例題：未知數在等號兩邊

解 5x − 3 = 2x + 9。

步驟一：把含 x 的項移到左邊、常數移到右邊。2x 移到左邊變成 −2x，−3 移到右邊變成 +3：5x − 2x = 9 + 3。
步驟二：合併同類項：3x = 12。
步驟三：x = 12 ÷ 3 = 4。

### 1-3-5 驗算

解出答案後，把解代回原方程式，檢查左右兩邊是否相等，稱為驗算。

以 1-3-4 為例，把 x = 4 代入 5x − 3 = 2x + 9：
左式 = 5 × 4 − 3 = 17，右式 = 2 × 4 + 9 = 17，左式 = 右式，所以 x = 4 是正確的解。

養成驗算的習慣，可以發現移項時忘記變號等錯誤。

## 1-4 含括號與分數的方程式

### 1-4-1 去括號

方程式中有括號時，先用分配律把括號展開，再用移項法則求解。

例題 1：解 2(x − 3) = 10。
展開：2x − 6 = 10。移項：2x = 16。得 x = 8。

例題 2：解 3(x + 2) − 2(x − 1) = 15。
展開：3x + 6 − 2x + 2 = 15。注意 −2 乘以 −1 得 +2。
合併：x + 8 = 15。得 x = 7。

### 1-4-2 去分母

方程式中有分數時，可以在等號兩邊同時乘以所有分母的最小公倍數，把分母去掉。

例題：解 x/2 + x/3 = 10。
分母 2 和 3 的最小公倍數是 6，兩邊同乘 6：3x + 2x = 60。
合併：5x = 60。得 x = 12。

### 1-4-3 例題：等號兩邊都有分數

解 (x − 1)/3 = (x + 3)/5。

兩邊同乘 15：5(x − 1) = 3(x + 3)。
展開：5x − 5 = 3x + 9。
移項：5x − 3x = 9 + 5，得 2x = 14，x = 7。
驗算：左式 = (7 − 1)/3 = 2，右式 = (7 + 3)/5 = 2，相等。

### 1-4-4 常見錯誤

錯誤一：去分母時，常數項漏乘。
解 x/2 + 1 = 5 時，兩邊同乘 2，應為 x + 2 = 10，得 x = 8。常見的錯誤是寫成 x + 1 = 10，漏乘了常數項 1。

錯誤二：移項忘記變號。
解 x − 4 = 6 時，−4 移到右邊應變成 +4，得 x = 10。常見的錯誤是寫成 x = 6 − 4 = 2。

錯誤三：括號前是負號，展開時只改第一項的符號。
−(x − 3) 應展開為 −x + 3，而不是 −x − 3。

## 1-5 應用問題

### 1-5-1 解應用問題的步驟

1. 設：找出題目要求的量，用 x 表示。
2. 列：找出題目中的等量關係，列出方程式。
3. 解：解出方程式。
4. 驗：檢查解是否合理（例如人數、年齡不能是負數或小數）。
5. 答：寫出答案，記得加上單位。

### 1-5-2 年齡問題

例題：父親今年 40 歲，兒子今年 12 歲。幾年後父親的年齡會是兒子的 2 倍？

設 x 年後，父親 40 + x 歲，兒子 12 + x 歲。
列式：40 + x = 2(12 + x)。
展開：40 + x = 24 + 2x。移項：40 − 24 = 2x − x，得 x = 16。
驗算：16 年後父親 56 歲、兒子 28 歲，56 = 2 × 28，正確。
答：16 年後。

### 1-5-3 價格問題

例題：買 3 枝筆和 1 本筆記本共 85 元，筆記本比一枝筆貴 25 元。一枝筆多少元？

設一枝筆 x 元，則筆記本 (x + 25) 元。
列式：3x + (x + 25) = 85。
合併：4x + 25 = 85。移項：4x = 60，得 x = 15。
驗算：筆 15 元、筆記本 40 元，3 × 15 + 40 = 85，正確。
答：一枝筆 15 元。

### 1-5-4 雞兔同籠

例題：籠子裡有雞和兔子共 20 隻，腳共有 56 隻。兔子有幾隻？

設兔子 x 隻，則雞有 (20 − x) 隻。兔子有 4 隻腳、雞有 2 隻腳。
列式：4x + 2(20 − x) = 56。
展開：4x + 40 − 2x = 56。合併：2x = 16，得 x = 8。
驗算：兔子 8 隻、雞 12 隻，4 × 8 + 2 × 12 = 56，正確。
答：兔子 8 隻。

### 1-5-5 行程問題

例題：小明從家裡到學校，走路每分鐘 60 公尺，騎腳踏車每分鐘 180 公尺。騎腳踏車比走路少花 10 分鐘。家裡到學校的距離是多少公尺？

設距離為 x 公尺。走路時間 x/60 分鐘，騎車時間 x/180 分鐘。
列式：x/60 − x/180 = 10。
兩邊同乘 180：3x − x = 1800，得 2x = 1800，x = 900。
驗算：走路 15 分鐘、騎車 5 分鐘，相差 10 分鐘，正確。
答：900 公尺。

## 本章範圍說明

本章只涵蓋一元一次方程式。二元一次聯立方程式、一元二次方程式、不等式等內容不在本章範圍內。
