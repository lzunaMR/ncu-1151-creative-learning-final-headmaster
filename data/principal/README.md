# 校長組：成績資料與校務文件

| 檔案 | 內容 |
| --- | --- |
| `scores.csv` | 三個學期的各科學期成績（結構化資料） |
| `docs/` | 同一所學校 1142 學期的校務文件（RAG 教材），每段標題帶有段落 id |

校務文件記錄了學期中發生的事件。**文件提到某件事，不代表成績一定受影響**，要用成績資料驗證。

## 成績資料

`scores.csv` 是一所虛構國中三個學期的各科學期成績，**全部由程式合成，不含任何真實學生資料**。

## 欄位

| 欄位 | 說明 | 範例 |
| --- | --- | --- |
| `semester` | 學期，前三碼為學年度、最後一碼為上 (1) / 下 (2) 學期 | `1132` = 113 學年度下學期 |
| `grade` | 年級（7–9） | `8` |
| `class` | 班級 | `805` |
| `student_id` | 學號 | `S1130512` |
| `subject` | 科目：國文、英文、數學、自然、社會 | `數學` |
| `score` | 分數（0–100）。**空白代表缺考** | `72` |

- 涵蓋學期：`1132`、`1141`、`1142`。最新一學期是 `1142`（114 學年度下學期）。
- 每個年級 6 個班，每班 25–30 人。
- 學號格式為 `S` + 入學學年度（3 碼）+ 班號（2 碼）+ 座號（2 碼）。
- 學生升年級時**不重新編班**：113 學年度的 703 班，到 114 學年度就是 803 班，學生相同。

## 注意

- 期末驗收會換一份**欄位相同、內容不同**的資料。不要把從這份資料看到的結論寫死在程式或 prompt 裡。
- 資料中沒有教師、出缺席、家庭背景等欄位。系統回答「原因」時，必須區分「資料顯示的事實」和「推測」。
